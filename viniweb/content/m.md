Este site existe como uma reação à internet moderna.

A internet já foi composta principalmente por pequenos sites pessoais. Pessoas criavam páginas próprias para compartilhar ideias, projetos, imagens, textos, obsessões, arquivos e experiências. Cada site tinha personalidade própria. Cada página refletia quem a construiu.

Não existiam feeds infinitos decidindo o que deveria ser visto. Não existiam algoritmos intermediando todas as relações humanas. A experiência de navegar era mais próxima de explorar territórios independentes do que consumir uma plataforma centralizada.

Com o tempo, grande parte da internet foi substituída por redes sociais. Em vez de visitar lugares, passamos a consumir fluxos infinitos de conteúdo controlados por plataformas. O conteúdo deixou de pertencer completamente às pessoas que o criaram. A web se tornou dependente de serviços, algoritmos, métricas e infraestrutura de terceiros.

Este site rejeita essa lógica.

Este é um espaço próprio. Um lugar independente na internet.

Todo o conteúdo aqui pertence a mim e existe fora de plataformas fechadas. Este site é programado manualmente, sem construtores visuais, sem sistemas gigantescos e sem depender de uma cadeia infinita de serviços externos para continuar funcionando.

Ele utiliza HTML, CSS e JavaScript puro. O site é gerado usando o SSG Zola. O conteúdo pode ser hospedado em praticamente qualquer servidor capaz de entregar arquivos estáticos. Também mantenho backups independentes e versionamento completo via Git.

Se necessário, este site pode existir:
- em um servidor alugado
- em múltiplos backups
- em um disco rígido offline
- ou em um computador físico dentro da minha própria casa servindo conteúdo diretamente para a internet

Este projeto foi pensado para sobreviver ao máximo possível sem depender de terceiros.

O desenvolvimento acontece prioritariamente offline. A internet é utilizada como meio de distribuição, não como requisito permanente para criação.

Eu rejeito tecnologias que exigem dependências excessivas, plataformas centralizadas ou serviços obrigatórios para existir. Prefiro sistemas simples, compreensíveis e duráveis.

Este site continuará recebendo atualizações constantes.

Porque páginas pessoais ainda importam.

Porque a web ainda pode ser humana.

Porque ter um lugar próprio na internet importa.
